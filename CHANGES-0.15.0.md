# What changed in 0.15.0

## New Pocket Controls screen (Vault Hunters style)
- Light bevelled panel with a dark board. The upgrades sit in colored groups: Space, Guests, Rest, Vault, Power.
- Every upgrade level is a small icon node: bright = unlocked, gold border = the next one you can buy, dim = locked.
- Hover a node to read what it does and what it costs (like the advancement tooltips). Click the gold node to buy it.
- Progress bar and your Starglass count next to the title. Vault has an Open button. Link a Gate / Take apart sit at the bottom.
- The Power group (Kinetic link: RPM and stress) is shown locked, "coming soon".

## New multiblock textures
- Casing, Core and Controls front redrawn (idle + active) in the same dark violet / lavender palette as the screen:
  plated casing with rivets and a glowing window, a smooth glowing orb for the Core, a console face for the Controls.

Everything from 0.14.0 and earlier is included.
